# Privacy Policy for AcilBir Remote Desktop

Last updated: August 2026

AcilBir Remote Desktop ("the Application") is an open-source remote support and device management client provided by ABT Bilgisayar.

### 1. Information We Process
To provide remote desktop connectivity and technical support services, the Application processes the following technical and account information:
- **Account Data:** Name, surname, and email address (when authenticated for support/management).
- **Device & System Data:** Device ID, computer/host name, operating system version, and IP addresses (used strictly for network routing and peer-to-peer handshakes).
- **Session Logs:** Timestamps and duration of remote support sessions (for security, audit, and quality assurance).

### 2. How Data is Used
- To establish secure remote desktop connections (P2P / Relay).
- To enable authorized technical support and device management.
- To maintain security audit logs and prevent unauthorized access.

### 3. Data Protection & Sharing
- All remote desktop traffic and screen streams are end-to-end encrypted.
- We **do not sell, rent, or monetize** any user or device data to third parties.
- Data is processed securely on our self-hosted infrastructure.
